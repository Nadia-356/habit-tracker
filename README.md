# Habit Tracker

A minimal and responsive habit tracker built with Vue 3.

Habit Tracker helps users organize their daily habits, track their progress, and stay motivated through a clean, nature-inspired interface.

**[Live Demo](https://habit-tracker-silk-seven.vercel.app/)**

## Features

- Add new habits
- Mark habits as completed or undo completion
- Edit and delete existing habits
- Track progress with a dynamic progress bar
- Display motivational feedback based on progress
- Automatically save habits using localStorage
- Reset habits with a confirmation dialog
- Responsive design for desktop and mobile devices

## Tech Stack

- **Vue 3** – Frontend framework
- **JavaScript** – Application logic
- **Composition API** – Reactive state management using `ref`, `computed`, and `watch`
- **HTML5 & CSS3** – Structure, styling, and responsive layouts
- **Vite** – Development and build tool
- **Git & GitHub** – Version control and source code hosting
- **Vercel** – Deployment and hosting

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nadia-356/habit-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd habit-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
